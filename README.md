## 📝 本地写作与维护指北

在本地编写新的 Markdown 笔记或调整站点配置时，常用的基础命令如下：

### 1. 启动本地开发服务
在终端执行以下命令，可以在本地开启带有热更新（HMR）的预览服务器，实时查看修改效果：
```bash
npm run docs:dev
```

### 2. 执行本地打包测试
在将代码推送到远程仓库前，如果想在本地测试静态文件是否能成功生成，可以运行：
```bash
npm run docs:build
```

### 3. 创建新笔记的注意事项
请确保新的 `.md` 文件放置在正确的顶级分类目录（如 `01-计算机与IT技术` 或 `02-驾考交规`）下。保存后，系统的自动化脚本会为您实时更新该板块的数据统计与目录导航。
