## Java 快速 IO

当输入/输出量**达到 $10^5 - 10^6$ 或者以上的时候**，就要考虑到使用自定义的 IO, 这样来解决输入/输出时间过长的问题。

可以这样记忆：
- 输入：
	1. 把**输入放入在字符流中，然后在把这个字符流经行缓存，得到有缓存的字符流**
	2. 为了比较**方便处理各个字符**，可以便于分割，那还需要引入相关的类-`StringTokenizer`-来处理
- 输出：也是同理，把它放入**字符输出流中，然后再经行缓存，为了方便打印，再嵌套一个 `PrintWriter`**
```Java
import java.util.*;
import java.io.*;

public class Main
{
    public static PrintWriter out = new PrintWriter(new BufferedWriter(new OutputStreamWriter(System.out)));
    public static Read in = new Read();
    
    public static void main(String[] args) throws IOException
    {
        // 写代码

        out.close();
    }
}


class Read // 自定义快速读入
{
    StringTokenizer st = new StringTokenizer("");
    BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
    String next() throws IOException 
    {
        while(!st.hasMoreTokens())
        {
            st = new StringTokenizer(bf.readLine());
        }
        return st.nextToken();
    }
    
    String nextLine() throws IOException 
    {
        return bf.readLine();
    }
    
    int nextInt() throws IOException 
    {
        return Integer.parseInt(next());
    }
    
    long nextLong() throws IOException 
    {
        return Long.parseLong(next());
    }
    
    double nextDouble() throws IOException 
    {
        return Double.parseDouble(next());
    }
}
```
