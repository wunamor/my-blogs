### [拼三角](https://ac.nowcoder.com/acm/problem/219046)

- 思路1: 把所有的情况都遍历一次，只要有一个条件满足，那么就可以返回 true
- 思路2: **思路1对于比较多的数据不太合适**，如果要判断比较多的三角形，就需要比较多的循环了，这显然不合适，因此可以采用递归的方式来解决
- 思路3: 这个是本题目的最优解，**可以先排序一下，然后就只需要判断 4 次就可以了**

|  案例   |          排除内容           |                    理由                     |
| :---: | :---------------------: | :---------------------------------------: |
| 0,1,2 | 0,1,3<br>0,1,4<br>0,1,5 | 如果 0,1,2 不满足<br>**那么3,4,5 这些更大的数据也一定不满足** |
| 0,2,3 |     0,2,4<br>0,2,5      |                  这些都是同理                   |
| 0,3,4 |          0,3,5          |                  这些都是同理                   |
| 0,4,5 |            -            |                  这些都是同理                   |

我这个是不太好，因为这个数据量只有 $10^3$ 完全不需要使用缓存
> 1. CPU 1s 可以计算 $10^8$ 常规的加减法
> 2. 由于 `Java` 中的 `Scanner` 有一系列的因素操作，因此一次输入消耗的时间就算它是 100 次常规的加减法
> 3. **所以在 $10^5-10^6$  这个数量级的输入的时候，就需要考虑输入对性能的影响了**


```Java
import java.util.*;
import java.io.*;

// 注意类名必须为 Main, 不要有任何 package xxx 信息
public class Main {

    static Reader in = new Reader();
    static PrintWriter out = new PrintWriter(new BufferedWriter(new OutputStreamWriter(System.out)));

    public static void main(String[] args) throws Exception {

        /**
        思路
            1. 排序，从小到大依次分开
            2. 然后分为左右两块，如果左边的不可以组成，那后面的更不行，同理右侧也一样
         */
        int t = in.nextInt();

        int n = 6;

        for (int i = 0; i < t; i++) {
            int[] arr = new int[n];
            for (int j = 0; j < n; j++) {
                arr[j] = in.nextInt();
            }

            Arrays.sort(arr);
            // out.println(Arrays.toString(arr));

            if ((arr[0] + arr[1] > arr[2] && arr[3] + arr[4] > arr[5]) ||
               (arr[0] + arr[2] > arr[3] && arr[1] + arr[4] > arr[5]) ||
               (arr[0] + arr[3] > arr[4] && arr[1] + arr[2] > arr[5]) ||
               (arr[0] + arr[4] > arr[5] && arr[1] + arr[2] > arr[3])
               ) {
                out.println("Yes");
            } else {
                out.println("No");
            }
        }
        

        out.close();
    }

}


class Reader {
    StringTokenizer st = new StringTokenizer("");
    BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

    String next() throws Exception {
        if (!st.hasMoreTokens()) {
            st = new StringTokenizer(br.readLine());
        }
        return st.nextToken();
    }

    int nextInt() throws Exception {
        return Integer.parseInt(next());
    }
}
```

### [DP13 [NOIP2002 普及组] 过河卒](https://www.nowcoder.com/practice/cc1a9bc523a24716a117b438a1dc5706?tpId=230&tqId=40428&ru=/exam/oj)

思路：
1. 状态表示：**`dp[i][j]` 的值表示从 `[0, 0]` 走到 `[i, j]` 这个位置路径的路径总数**
2. 递推方程：
	- 如果是马占据的位置，那么这个位置的值就是为 0
	  > 马一次跳跃到达的点(x1,y1)和马原坐标(x,y)的关系是 ∣x1−x∣+∣y1−y∣=3，且 1≠x,y1≠y ∣x1−x∣+∣y1−y∣=3，且 x1 ≠ x, y1 ≠ y
	- 如果不是，那么 `dp[i][j] = dp[i - 1][j] + dp[i][j - 1]`
3. 为了处理边界情况，二维的数组的长度/宽度还需要在之前的基础上加上 1

```Java
import java.util.*;

// 注意类名必须为 Main, 不要有任何 package xxx 信息
public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt() + 1, m = in.nextInt() + 1, x = in.nextInt() + 1, y = in.nextInt() + 1; // 整体向右下移动一格

        long[][] dp = new long[n + 1][m + 1];
        dp[0][1] = 1; // 兼容 dp[1][1]，原地不动也算是一种路径
        
        for (int i = 1; i < n + 1; i++) {
            for (int j = 1; j < m + 1; j++) {
                // 在马占据的位置，路径的个数为 0, 而 Java 中默认的初始化的值为 0, 因此不需要处理
                if ((i != x && j != y && Math.abs(i - x) + Math.abs(j - y) == 3) || (i == x && j == y)) continue;
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }

        System.out.println(dp[n][m]);
    }
}

```

### [游游的水果大礼包](https://ac.nowcoder.com/acm/problem/255193)
这个题目的难点是不能使用贪心算法，**而是使用枚举的策略**。

举一个反例就可以证明：

| 序号  | 例子（n,m,a,b） |           正确情况           |
| :-: | :---------: | :----------------------: |
|  1  | 3 100 10 9  | 应该是 `9 * 3` 而不是 `10 * 1` |

细节：要考虑 `int` 会溢出的情况，要使用 `long`

```Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt(), a = in.nextInt(), b = in.nextInt();
        long result = 0;
        // i 是 a 元水果大礼包个数
        for (int i = 0; i <= n / 2 && i <= m; i++) {
            // j 是 b 元水果大礼包的个数
            int j = Math.min(n - 2 * i, (m - i) / 2);
            result = Math.max(1l * a * i + 1l * b * j, result); // 防止溢出
        }
        
        System.out.println(result);
    }
}
```

### [mari和shiny](https://ac.nowcoder.com/acm/problem/26226)
这个题目要求的是构成 `shy`，而且 **s 必须在 h 前面， h 必须在 y 前面才能构成**

思路：
1. 如何组装 `shy` 呢？看到一个 `y`，**那么就要知道前面有多少个 `sh`**，然后与之前的已经构成的 `shy` 累加
2. 那么如何知道前面有多少个 `sh` 呢？同理，看见一个 `h`，**就要知道前面有多少个 `s`**，然后和之前构成的 `sh` 累加即可
3. 同理看见 `s` 也一样，最后算出来的 `shy` 的个数就是要求的结果
> 为什么这样可以做到不重不漏？
> 
> 就以看见 y 为例，**此时 sh 的个数就是这个位置的 y 所有匹配的值**，其他的也同理，因此不会重复
```Java
import java.util.*;

public class Main {
    static char[] keys = {'s', 'h', 'y'}; // 顺序必须为 s h y
    static int len = keys.length;
    static int[] indexs = {0, 1, 2};
    static long[][] counts = new long[len][]; // counts[0] 对应的是 s 的 dp 数组

    
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        
        int n = in.nextInt();
        in.nextLine();
        char[] arr = in.nextLine().toCharArray();
        for (int i = 0; i < len; i++) {
            counts[i] = new long[n + 1]; // 初始化 dp 
        }
        
        int index;
        for (int i = 1; i <= n; i++) { // dp从 1 下标开始
            char ch = arr[i - 1];
            if ((index = getIndex(ch)) != -1) {
                if (index == 0) counts[index][i] = counts[index][i - 1] + 1;
                else counts[index][i] = counts[index][i - 1] + counts[index - 1][i - 1];
            }
            // 其他的也要更新
            for (int j = 0; j < len; j++) {
                if (index != j) counts[j][i] = counts[j][i - 1];
            }
        }
        
//         print(counts);
        System.out.println(counts[len - 1][n]);
    } 
    static void print(long[][] arr) {
        for (int i = 0; i < arr.length; i++) {
            System.out.println(Arrays.toString(arr[i]));
        }
    }
    
    static int getIndex(char ch) {
        for (int i = 0; i < len; i++) {
            if (keys[i] == ch) return indexs[i];
        }
        return -1;
    }
}
```

### [重排字符串](https://ac.nowcoder.com/acm/problem/222104)✅
找到规律：
1. 如果最多的字符的个数**大于一半**的时候，那就**一定不能重排**，如果小于，那就一定可以重排
2. **每隔一个字符放一个相同的字符**，是最高效的方法
3. **最多字符的需要从第一个开始排序**，需要考虑相同字符占一半并且是字符的总个数为奇数的情况

```Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        in.nextLine();
        char[] arr = in.nextLine().toCharArray();
        
        int len = 26;
        int[] counts = new int[len]; 
        
        // 计数
        for (char ch : arr) {
            counts[ch - 'a']++;
        }
        
        // 找到最大值极其相关字符
        int maxIndex = 0, max = counts[0];
        for (int i = 1; i < len; i++) {
            if (counts[i] > max) {
                max = counts[i];
                maxIndex = i;
            }
        }
//         System.out.println("maxIndex = " + maxIndex);
//         System.out.println("max = " + max);
        
        // 排除
        if (max > (n + 1) / 2) {
            System.out.println("no");
            return;
        }
        
//         System.out.println(Arrays.toString(counts));
		// 遍历执行
        int index = maxIndex, gap = 2;
        char[] result = new char[n];
//         System.out.println("=============================");
//         print(result);
        for (int i = 0; i < gap; i++) {
            for (int j = i; j < n; j += gap) {
                if (counts[index] == 0) index = getIndex(counts);
                counts[index]--;
                result[j] = (char)(index + 'a');
            }
        }
//         System.out.println(Arrays.toString(counts));
//         print(result);
        
        System.out.println("yes");
        System.out.println(new String(result));
    }
    
    static void print(char[] arr) {
        for (int i = 0; i < arr.length; i++) {
            System.out.print((int)arr[i] + " ");
        }
        System.out.println();
        
    }
    
    // 找到 counts 的值不为 0 的下标
    static int getIndex(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] != 0) return i;
        }
        return -1;
    }
}
```

### [DP25 删除相邻数字的最大分数](https://www.nowcoder.com/practice/3bcf72c738b6494bbe1ebe0ffde56152?tpId=230&tqId=40419&ru=/exam/oj)

- 首先，这个题目是把相同的数字一起处理的，**因此需要先预处理，把相同的数字放在一个区域 `sum`**。
- 然后设置 `dp`，
	- 定义：
		- `c`: 选择的时候，获取的最大分数
		- `nc`: 不选择的时候，获取的最大分数
	- 递推公式：
		- `c[i] = nc[i - 1] + sum[i]`
		- `nc[i] = max(nc[i - 1], c[i])`

```Java
import java.util.*;

// 注意类名必须为 Main, 不要有任何 package xxx 信息
public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] arr = new int[n];
        int max = 0;
        for (int i = 0; i < n; i++) {
            arr[i] = in.nextInt();
            max = Math.max(max, arr[i]);
        }
        int len = max + 1;
        int[] sum = new int[len]; // sum[i] 表示 i 个数数字的之和

        for (int x : arr) {
            sum[x] += x;
        }

        // choice, no choice
        int[] c = new int[len]; // 选择时候的它们之和的最大值
        int[] nc = new int[len]; // 没有选择的它们之和的最大值

        for (int i = 1; i < len; i++) {
            c[i] = nc[i - 1] + sum[i];
            nc[i] = Math.max(nc[i - 1], c[i - 1]);
        }

        System.out.println(Math.max(nc[len - 1], c[len - 1]));
    }
}
```
