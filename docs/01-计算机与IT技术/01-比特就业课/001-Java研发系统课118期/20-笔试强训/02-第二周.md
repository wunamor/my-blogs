### [拼三角](https://ac.nowcoder.com/acm/problem/219046)

- 思路1: 把所有的情况都遍历一次，只要有一个条件满足，那么就可以返回 true
- 思路2: **思路1对于比较多的数据不太合适**，如果要判断比较多的三角形，就需要比较多的循环了，这显然不合适，因此可以采用递归的方式来解决
- 思路3: 这个是本题目的最优解，**可以先排序一下，然后就只需要判断 4 次就可以了**

|  案例   |          排除内容           |                    理由                     |
| :---: | :---------------------: | :---------------------------------------: |
| 0,1,2 | 0,1,3<br>0,1,4<br>0,1,5 | 如果 0,1,2 不满足<br>**那么3,4,5 这些更大的数据也一定不满足** |
| 0,2,3 |     0,2,4<br>0,2,5      |                  这些都是同理                   |
| 0,3,4 |          0,3,5          |                  这些都是同理                   |
| 0,4,5 |            -            |                  这些都是同理                   |

我这个是不太好，因为这个数据量只有 $10^3$ 完全不需要使用缓存
> 1. CPU 1s 可以计算 $10^8$ 常规的加减法
> 2. 由于 `Java` 中的 `Scanner` 有一系列的因素操作，因此一次输入消耗的时间就算它是 100 次常规的加减法
> 3. **所以在 $10^5-10^6$  这个数量级的输入的时候，就需要考虑输入对性能的影响了**


```Java
import java.util.*;
import java.io.*;

// 注意类名必须为 Main, 不要有任何 package xxx 信息
public class Main {

    static Reader in = new Reader();
    static PrintWriter out = new PrintWriter(new BufferedWriter(new OutputStreamWriter(System.out)));

    public static void main(String[] args) throws Exception {

        /**
        思路
            1. 排序，从小到大依次分开
            2. 然后分为左右两块，如果左边的不可以组成，那后面的更不行，同理右侧也一样
         */
        int t = in.nextInt();

        int n = 6;

        for (int i = 0; i < t; i++) {
            int[] arr = new int[n];
            for (int j = 0; j < n; j++) {
                arr[j] = in.nextInt();
            }

            Arrays.sort(arr);
            // out.println(Arrays.toString(arr));

            if ((arr[0] + arr[1] > arr[2] && arr[3] + arr[4] > arr[5]) ||
               (arr[0] + arr[2] > arr[3] && arr[1] + arr[4] > arr[5]) ||
               (arr[0] + arr[3] > arr[4] && arr[1] + arr[2] > arr[5]) ||
               (arr[0] + arr[4] > arr[5] && arr[1] + arr[2] > arr[3])
               ) {
                out.println("Yes");
            } else {
                out.println("No");
            }
        }
        

        out.close();
    }

}


class Reader {
    StringTokenizer st = new StringTokenizer("");
    BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

    String next() throws Exception {
        if (!st.hasMoreTokens()) {
            st = new StringTokenizer(br.readLine());
        }
        return st.nextToken();
    }

    int nextInt() throws Exception {
        return Integer.parseInt(next());
    }
}
```


## Day10
### [DP13 [NOIP2002 普及组] 过河卒](https://www.nowcoder.com/practice/cc1a9bc523a24716a117b438a1dc5706?tpId=230&tqId=40428&ru=/exam/oj)

思路：
1. 状态表示：**`dp[i][j]` 的值表示从 `[0, 0]` 走到 `[i, j]` 这个位置路径的路径总数**
2. 递推方程：
	- 如果是马占据的位置，那么这个位置的值就是为 0
	  > 马一次跳跃到达的点(x1,y1)和马原坐标(x,y)的关系是 ∣x1−x∣+∣y1−y∣=3，且 1≠x,y1≠y ∣x1−x∣+∣y1−y∣=3，且 x1 ≠ x, y1 ≠ y
	- 如果不是，那么 `dp[i][j] = dp[i - 1][j] + dp[i][j - 1]`
3. 为了处理边界情况，二维的数组的长度/宽度还需要在之前的基础上加上 1

```Java
import java.util.*;

// 注意类名必须为 Main, 不要有任何 package xxx 信息
public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt() + 1, m = in.nextInt() + 1, x = in.nextInt() + 1, y = in.nextInt() + 1; // 整体向右下移动一格

        long[][] dp = new long[n + 1][m + 1];
        dp[0][1] = 1; // 兼容 dp[1][1]，原地不动也算是一种路径
        
        for (int i = 1; i < n + 1; i++) {
            for (int j = 1; j < m + 1; j++) {
                // 在马占据的位置，路径的个数为 0, 而 Java 中默认的初始化的值为 0, 因此不需要处理
                if ((i != x && j != y && Math.abs(i - x) + Math.abs(j - y) == 3) || (i == x && j == y)) continue;
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }

        System.out.println(dp[n][m]);
    }
}

```

### [游游的水果大礼包](https://ac.nowcoder.com/acm/problem/255193)
这个题目的难点是不能使用贪心算法，**而是使用枚举的策略**。

举一个反例就可以证明：

| 序号  | 例子（n,m,a,b） |           正确情况           |
| :-: | :---------: | :----------------------: |
|  1  | 3 100 10 9  | 应该是 `9 * 3` 而不是 `10 * 1` |

细节：要考虑 `int` 会溢出的情况，要使用 `long`

```Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt(), a = in.nextInt(), b = in.nextInt();
        long result = 0;
        // i 是 a 元水果大礼包个数
        for (int i = 0; i <= n / 2 && i <= m; i++) {
            // j 是 b 元水果大礼包的个数
            int j = Math.min(n - 2 * i, (m - i) / 2);
            result = Math.max(1l * a * i + 1l * b * j, result); // 防止溢出
        }
        
        System.out.println(result);
    }
}
```
