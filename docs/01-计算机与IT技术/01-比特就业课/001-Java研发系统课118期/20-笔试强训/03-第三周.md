### [分组](https://ac.nowcoder.com/acm/problem/229023)
#### 解法一，贪心 ✅
它需要在**长度尽可能小**的情况下，求出最长的长度，需要使用想要用优先级队列，每一次分配一个空间，就要把把最长的长度变小，直到变为 1 为止。

```Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt();
        int[] counts = new int[n + 1];
        for (int i = 0; i < n; i++) {
            counts[in.nextInt()]++;
        }
        
        // 使用优先级队列来解决 [mCount, maxLen, totalCount]: 分配的组的个数，数组的元素的最多个数，总个数
        PriorityQueue<int[]> queue = new PriorityQueue<>((n1, n2) -> n2[1] - n1[1]);
        for (int i = 1; i <= n; i++) { // 值的范围是 [1, n]
            if (counts[i] != 0) queue.add(new int[]{1, counts[i], counts[i]}); // 默认该类似分配的组数是一，因此数组的元素个数为 counts[i]
        }
        
        // m 太小，无法分配
//         print(queue);
        if (queue.size() > m) {
            System.out.println(-1);
            return;
        }
        
        m -= queue.size(); // 减去已经使用的数组个数
        
        while (m-- != 0) {
            int[] tmp = queue.poll(); // 一定要先弹出再加入，不然优先级队列不会排序
			if (tmp[1] == 1) break; // 最长的长度为 1, 那么就不需要分配了

            tmp[0]++; // 分配的个数加 1 
            tmp[1] = tmp[2] / tmp[0] + (tmp[2] % tmp[0] == 0 ? 0 : 1); // 计算新的最长的数组的长度
            queue.add(tmp); // 添加回去
        }
        System.out.println(queue.peek()[1]);
//         print(queue);
    }
    
    static void print(PriorityQueue<int[]> queue) {
//         PriorityQueue<int[]> queue = new PriorityQueue<int[]>();
        while (!queue.isEmpty()) {
            System.out.println(Arrays.toString(queue.poll()));
        }
    }
}
```

这个写法也可以优化一下：
1. **`m` 每一次不一定是减去 1**, 可以根据第二大多的元素进行判断
   > 比如最长的元素个数为 100, 此时已经给它分配了 2 个数组，那么它最长的长度为 50,
   >
   > 而第二长的元素个数为 20, 给它分配了 3 个数组，那么长度就是 7
   > 
   > 那么就可以直接计算相差个数 `diff`：
   > 1. `mCount = ceil(100 / (7 - 1))`
   > 2. `mCount = diff - 2`
   
2. 分配的数组的个数和元素的个数一样的时候，那么就不需要添加会队列里面了

#### 解法二，二分
首先先想到暴力解法：
1. 发现它是把相同的数字放在一起，因此是要先统计一下相同数组出现的次数, 它们的结果集为 `counts`
2. 判断一下，如果不同数字的类别超过了 m，那么就说明分配不了
3. **接着遍历区间 `[1, max]`** 其中 `max` 表示 `counts` 里面值最大的（最大的情况是每一个数组的容纳的元素个数为 `max`)
4. **发现上面那一步是判断一次，排除某一块区间，因此可以使用二分**

```Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt(), m = in.nextInt();
        int[] _counts = new int[n + 1];
        int max = 0;
        for (int i = 0; i < n; i++) {
            max = Math.max(max, ++_counts[in.nextInt()]);
        }
        
        List<Integer> counts = new ArrayList<>();
        for (int x : _counts) if (x != 0) counts.add(x);
        
//         System.out.println(counts);
        // 二分
        int left = 1, right = max; // 数组长度的范围 
        if (counts.size() > m) {
            System.out.println(-1);
            return;
        }
        while (left < right) {
            int mid = (right - left) / 2 + left; // 每个组的人数
//             System.out.println("left = " + left + ", mid = "+ mid + ", right = " + right);
            int tmp = 0;
            for (int x : counts) {
                tmp += x / mid + (x % mid == 0 ? 0 : 1);
            }
//             System.out.println("tmp = " + tmp);
            if (tmp > m) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        System.out.println(right);
    }
}
```
