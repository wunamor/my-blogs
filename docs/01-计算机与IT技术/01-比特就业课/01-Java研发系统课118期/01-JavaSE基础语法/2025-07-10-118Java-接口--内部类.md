# 2025-07-10-接口--内部类
|    类型    |         特点         |                                           用途                                           |                   演示图例                   |
| :--------: | :------------------: | :--------------------------------------------------------------------------------------: | :------------------------------------------: |
| 静态内部类 | 静态，用 static 修饰 | 当内部类不需要访问外部实例，如果不用，可能会有内存隐式泄漏，因为此时内部类是依赖与外部类 | ![](images/2025-07-10-内部类-静态内部类.png) |
| 实例内部类 |    不需要其他修饰    |                          需要依赖与外部类，比如集合类中的迭代器                          | ![](images/2025-07-10-内部类-实例内部类.png) |
| 匿名内部类 |       没有类名       |                        可以配合接口使用，一般缩写为 Lambda 表达式                        | ![](images/2025-07-10-内部类-匿名内部类.png) |
| 局部内部类 |    在方法内部创建    |                                         基本没有                                         | ![](images/2025-07-10-内部类-局部内部类.png) |
