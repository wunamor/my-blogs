# 2025-07-27-二叉树

## 重要性质
1. 二叉树 **叶子节点的个数 = 度为 2 的节点个数 + 1**
  即 $N_0 = N_2 + 1$

    > 令 $N$ 为节点总个数，$E$ 是边的总数，$N_0$ 为度为 0 的节点,
    > $N_1$ 为度为 1 的节点, $N_2$ 为度为 2 的节点
    >
    > 由于 **除了根节点以外的的节点都有且只有一个父节点**，所以 $E = N - 1$
    > 
    > 显然 $E = 0*N_0 + 1 * N_1 + 2 * N_2$
    > 得出 $N_1 + 2 * N_2 = N - 1 = N_0 + N_1 + N_2 - 1$
    >
    > 所以 $N_2 = N_0 - 1$


## 问题
### 在具有 2n 个结点的完全二叉树中，叶⼦结点个数为（ ）
- 问题
  ```text
  2.在具有 2n 个结点的完全⼆叉树中，叶⼦结点个数为（ ）
  A n
  B n+1
  C n-1
  D n/2
  ```

- 解释：
  ![](images/2025-07-27-二叉树-问题-在具有2n个结点的完全二叉树中，叶⼦结点个数为-解释.svg)
  1. 节点为偶数个的完全二叉树的 **度为 1 的节点个数为 1**
  2. 二叉树 **叶子节点的个数 = 度为 2 的节点个数 + 1**
  3. 计算出结果：
      $$
      \left\{
      \begin{aligned}
      N_0 &= N_2 + 1 \\
      2n &= N_0 + N_1 + N_2
      \end{aligned}
      \right.
      \implies
      2n = 2N_2 + N_1 + 1
      $$

      答案选 `A`

- 总结：但凡要计算节点的都需要想到 $N_0 = N_2 + 1$ 这个公式
