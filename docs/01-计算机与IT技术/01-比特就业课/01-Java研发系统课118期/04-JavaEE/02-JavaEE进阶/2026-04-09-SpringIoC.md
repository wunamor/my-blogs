# 2026-04-09-SpringIoC
IoC 是一个设计思想，翻译的名称叫作控制反转。就是把对象创建的控制权交给第三方来实现。在 Spring 中也就是交给 Spring 容器来管理。

## DI
DI 表示注入，第三方把管理好的对象注入给要使用的地方。

## 注解

| 类型             | 意思               |
| -------------- | ---------------- |
| @Controller    | 表示控制层，其他注解是无法替代的 |
| @Service       | 表示服务层            |
| @Repository    | 用来操作数据的          |
| @Component     | 其他的组件            |
| @Configuration | 表示这个文件是配置功能      |
