## `qrcode` 二维码生成
1. 先通过 `pip` 下载
   1. 最好去[官网](https://pypi.org/)里面搜索 `qrcode`
   2. 复制下载链接：
    ```bash
    pip install "qrcode[pil]"
    ```
2. 使用
    ```Python
    import qrcode

    # 制造二维码
    ret = qrcode.make("https://gitee.com/wunameor/bite-code/blob/master/python_basic/PythonProject/code63.py")
    ret.save('code63-url.png') # 保存二维码
    ```
3. 结果 **(tip: 陌生的二维码不要扫)**

## excel 表格操作
1. 先通过 `pip` 下载
    ```bash
    pip install xlrd==1.2.0 # 版本用 1.2.0 太高的不支持 xlsx
    ```
2. 使用：
    ```Python
    import xlrd

    # 读取到文件
    file = xlrd.open_workbook('./code64-test.xlsx')

    # 获取到表格
    table = file.sheet_by_index(0)

    count = 0
    total_score = 0
    for index in range(1, table.nrows):
        # 第 index 行 第 0 列
        class_id = table.cell_value(index, 0)
        if class_id == 1101:
            total_score += table.cell_value(index, 3)
            count += 1

    print(f'平均分为 {total_score / count}') # 平均分为 96.66666666666667

    ```
