# 聊天模型

## 定义工具
### `@tool` 使用
#### `Schema` 用处
  > 它是用来表示 相关对象的 属性，以便比较方便地调用这个对象
  >
  > 就拿 `JSON` 举例，
  > ```JSON
  > {
  >   "id": 1, 
  >   "name": "xiaoming", 
  >   "age": 18
  > }
  > ```
  >
  > 那这个 `JSON` 的 `Schema` 是
  > ```JSON
  > {
  >   "id": {"type": "integer"}, 
  >   "name": {"type": "string"}, 
  >   "age": {"type": "integer"}
  > }
  > ```
  > 它就可以比较方便的表示各个字段的属性

#### `@tool` 的 `Schema`
- 名称：即方法名称
- 描述：方法的使用文档
- 参数：方法的参数

![](images/聊天模型-定义工具-@tool%20使用-@tool%20的%20Schema.png)

`@tool` 的 `Schema` 的目的：
  - 根据**名称**可以让模型知道**调用哪个函数**
  - 根据**描述**可以让模型知道**提示词**
  - 根据**参数**可以让模型知道**需要传入的参数类型**
