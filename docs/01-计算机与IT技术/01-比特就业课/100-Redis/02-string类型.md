# 02-string类型

## 命令
### `get` 和 `set`
除了基本的用法， set 还有一系列的参数：
- `NX/XX`: `NX` 如果没有那么就创建，有就不创建了，`XX` 则相反。**这个不需要背，要用的时候测试一下就可以**
- `EX`: 设置有效时间，单位为秒

### `incr` 和 `decr`
`incr` 是**自增** 1, `decr` 是**自减** 1 。 

当然，它们还有衍生的，`incrby/decrby` 后面是添加数字的，如果这个 key 不存在，那么就默认是从 0 开始。

如果想要小数增加，那么就使用 `incrbyfloat` 来执行就可以了

### `append`
用来追加字符串的
> 可以追加中文，但是保存的内容是 \xea 这样的16进制，
> 
> 如果**想要通过 get 获取到中文，那么就需要在连接服务器之前就需要添加 `--raw` 这个参数命令**

### `setrange` 和 `getrange`
`setrange` 是表示设置一段范围内的内容
- key 不存在：那么就会在前面添加 \x00 用来占位
- value 长度过长：那么就会设置一段区间内

`getrange` 也是类似，获取一段范围内的内容，但是需要注意的是它是**前闭后闭**的，而且它像 `Python` 那样**支持负数**

### `strlen`
返回的字符串的长度

## 编码方式
在 `Redis` 中 `string` 类型有三种编码方式：`embstr`, `int` 和 `raw`
- `int`: 它是**存储 8 字节** 64 位的整数，等价于 `Java` 中的 `long` 类型
- `embstr`: 在**小于** 39 字节的情况下，是这个压缩的类型
- `raw`: 在**大于** 39 字节的情况下，会使用这个类型
> 不需要记住 `39` 这个数字，而是要着重理解为什么是 `39` 这个数字，**因为这个数字是可以配置的，在不同的场景下，配置的数字一般是不同的**
