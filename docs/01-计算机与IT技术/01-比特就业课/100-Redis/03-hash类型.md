# 03-hash类型
## 命令
### `hset` 和 `hget`
**`hset` 是存储内容，`hget` 是获取的内容**

同理 **`hset` 是可以批量存储的**
### `hdel`
**删除 `hash` 的指定 `field`**，也可以支持**批量删除**

### `hkeys`，`hvals` 和 `hgetall`
`hkeys` 是获取到 `hash` 中的**所有键**， `hvals` 是获取到 `hash` 中的**所有值**，`hgetall` 是把 `hkeys` 和 `hvals` 结合起来了，它是获取到**所有的键和值**

当然这两个命令和 `keys` 有一定的相似之处，都是会遍历一边相关对象，因此**执行的时候一定要慎重**

### `hmget`
**`hmget` 是批量获取值**，但是不是一口气全部获取

## 应用场景

### 缓存
`hash` 类型是依然可以作为缓存。相比与 `string` 类型，它显示比较直观，**获取/修改某个 `field` 是比较方便的，但是内存开销会比较高**
> `string` 如果想要获取/修改某个 `field`，它是需要获取/更改整个 `JSON`, 相比与 `hash` 来说是比较麻烦的
