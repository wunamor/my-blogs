# 04-前缀和

## 算法原理
当需要快速地求出一段连续数组区间的和时候，就需要使用它了

1. 把数据经行预处理，先生成 `dp` 数组，**它的长度是原数组 `arr`（令第一个数据的下标为 1） 的总长度 + 1**
2. 接着把 `dp` 第一个数据设置为 0, **`dp[i]` 表示 `[1, i]` 这个区间内 `arr` 数据之和（**求和可以使用 dp[i] = dp[i - 1] + arr[i] 来计算）
3. 如果要算出 `[n, m]` 区间内的值，那么只需要计算 `dp[m] - dp[n - 1]` 即可

## 题目
### [NC35. 搜索插入位置](https://leetcode.cn/problems/search-insert-position/description/)
思路就是和上面“算法原理”一样

<NCDP32PrefixSum />

```Java
public static void main(String[] args) {
    Scanner in = new Scanner(System.in);
    // 注意 hasNext 和 hasNextLine 的区别
    while (in.hasNextInt()) { // 注意 while 处理多个 case
        int len = in.nextInt();
        int q = in.nextInt();
        long[] dp = new long[len + 1]; // 设置为 long 防止越界
        // 处理 dp 从下标 1 开始
        for(int i = 1; i < dp.length; i++) {
            dp[i] = dp[i - 1] + in.nextInt();
        }

        // 计算结果
        for (int i = 0; i < q; i++) {
            System.out.println(-dp[in.nextInt() - 1] + dp[in.nextInt()]);
        }
    }
}
```

### [DP35 【模板】二维前缀和](https://www.nowcoder.com/practice/99eb8040d116414ea3296467ce81cbbc?tpId=230&tqId=2023819&ru=/exam/oj&qru=/ta/dynamic-programming/question-ranking&sourceUrl=%2Fexam%2Foj%3Fpage%3D1%26tab%3D%25E7%25AE%2597%25E6%25B3%2595%25E7%25AF%2587%26topicId%3D196)
这是是一个二维的前缀和，思路和之前的一样：先求 dp 然后再计算（**建议通过画图来理解**）
1. 求dp: `dp[i, j]` 它是表示`[1, 1]` 到 `[i, j]` 这个区间内的和。它是可以通过 `dp[i][j] = dp[i - 1][j] + dp[i][j - 1] - dp[i - 1][j - 1] + arr[i][j]` 来求出相关的值
2. 计算：通过 dp 来计算，可以通过 `dp[x2][y2] - dp[x2][y1 - 1] - dp[x1 - 1][y2] + dp[x1 - 1][y1 - 1]` 来求出题目中的结果 

<NCDP35PrefixSum2D />

```Java
public static void main(String[] args) {
	Scanner in = new Scanner(System.in);
	int n = in.nextInt(), m = in.nextInt(), q = in.nextInt();
	long[][] dp = new long[n + 1][m + 1];

	for (int i = 1; i < dp.length; i++) {
		for (int j = 1; j < dp[i].length; j++) {
			dp[i][j] = dp[i - 1][j] + dp[i][j - 1] - dp[i - 1][j - 1] + in.nextInt();
		}
	}

	// 注意 hasNext 和 hasNextLine 的区别
	while (in.hasNextInt()) { // 注意 while 处理多个 case
		int x1 = in.nextInt(), y1 = in.nextInt(), x2 = in.nextInt(), y2 = in.nextInt();
		System.out.println(dp[x2][y2] - dp[x2][y1 - 1] - dp[x1 - 1][y2] + dp[x1 - 1][y1 - 1]);
	}
}
```


### [LC724. 寻找数组的中心下标](https://leetcode.cn/problems/find-pivot-index/description/)

这个使用两个数组来表示，一个是前缀和，一个是后缀和

其中 f 是前缀和，g 是后缀和，
**`f[i]` 表示 `[0, i - 1]` 区间内的值， `g[i]` 表示 `[i + 1, n - 1]` 区间的值**

<LC724PivotIndex />

```Java
public int pivotIndex(int[] nums) {
	int n = nums.length;
	// f 表示从前往后的 dp 数组， g 是表示从后往前的
	// f[i] 表示 [0, i - 1] 区间内的值， g[i] 表示 [i + 1, n - 1] 区间的值
	int[] f = new int[n], g = new int[n];
	
	// 初始化 f
	for (int i = 1; i < n; i++) {
		f[i] = nums[i - 1] + f[i - 1];
	}

	// 初始化 g
	for (int i = n - 2; i >= 0; i--) {
		g[i] = g[i + 1] + nums[i + 1];
	}

	// 判断
	for (int i = 0; i < n; i++) {
		if (f[i] == g[i]) return i;
	}
	return -1;
}
```

--- 
当然这道题目也可以不用前缀和思想，先求总和，然后根据总和算出左右区间，那么就解决这个题目

<LC724PivotIndexTotalSum />

```Java
public int pivotIndex(int[] nums) {
	// 先求和
	int n = nums.length;
	int sum = 0;
	for (int i = 0; i < n; i++) {
		sum += nums[i];
	}

	// 定义左边的和和右边的和
	int i = 0, sumLeft = 0, sumRight = sum - nums[i];
	for (; i < n - 1; i++) {
		if (sumLeft == sumRight) return i;
		sumLeft += nums[i];
		sumRight -= nums[i + 1];
	}

	return sumLeft == sumRight ? n - 1 : -1;
}
```


### [LC238. 除了自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/description/)

这道题和上面的 LC724. 寻找数组的中心下标 思路一样，只不过把求和变为求积了而已。

**`f[i]` 表示 `[0, i - 1]` 区间内的积， `g[i]` 表示 `[i + 1, n - 1]` 区间的积**

<LC238ProductExceptSelf />

```Java
public int[] productExceptSelf(int[] nums) {
	int n = nums.length;
	// 先算出前缀 和 后缀
	int[] f = new int[n], g = new int[n];

	// f[i] 表示 [0, i - 1] 这个区间的积 g[i] 表示 [i + 1, n - 1] 的数量积
	f[0] = 1;
	for (int i = 1; i < n; i++) {
		f[i] = f[i - 1] * nums[i - 1];
	}

	g[n - 1] = 1;
	for (int i = n - 2; i >= 0; i--) {
		g[i] = g[i + 1] * nums[i + 1];
	}

	int[] result = new int[n];

	for(int i = 0; i < n; i++) {
		result[i] = f[i] * g[i];
	}

	return result;
}
```
