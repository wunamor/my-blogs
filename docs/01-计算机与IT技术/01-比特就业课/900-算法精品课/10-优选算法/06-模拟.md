# 06-模拟

模拟题是思路是相对来说是比较简单的，因为**不需要思考思路，题目是会自动给出过程的**。

但是在编写之前，**一定要画图，不然会忽略一些细节，这就会导致一些问题会无从下手**

## 题目

### [LC1576.替换所有的问号](https://leetcode.cn/problems/replace-all-s-to-avoid-consecutive-repeating-characters/description/)

这个题目只需要考虑一个细节就可以了：既**在最左侧和最右侧的时候，需要考虑下标越界的情况**

```Java
public String modifyString(String s) {
	char[] arr = s.toCharArray(); // 转换为数组可以比较方便处理
	int n = arr.length;
	for (int i = 0; i < arr.length; i++) {
		char ch = arr[i];
		if (ch == '?') {
			// 给 lCh 和 rCh 一个初始值，这样可以处理当 i 为 0 或 n - 1 的情况：不存在的话，不会保语法错误
			char lCh = 'd', rCh = 'e';
			if (i - 1 >= 0) lCh = arr[i - 1];
			if (i + 1 < arr.length) rCh = arr[i + 1];

			// 只要两次判断就可以了，因为两边最多是两个字符
			if (lCh != 'a' && rCh != 'a') arr[i] = 'a';
			else if (lCh != 'b' && rCh != 'b') arr[i] = 'b';
			else arr[i] = 'c';
		}
	}

	return new String(arr);
}
```
