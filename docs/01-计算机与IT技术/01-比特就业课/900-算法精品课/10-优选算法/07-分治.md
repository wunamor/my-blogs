分治是分而治之，**它是将一个大的问题拆分为若干的相同/相似的小问题**，而这些小问题是可以快速地解决的，从而推广到解决大问题

它分为两个模块：快排和归并

## 快排
### [LC75. 颜色分类](https://leetcode.cn/problems/sort-colors/)

这个是把这个数组分为四个部分，需要使用三个指针

定义三个指针 `left`, `i`, `right` 
- `[0, left]`: 全是 0 的数 
- `[left + 1, i - 1]`: 全是 1
- `[i, right - 1]`: 待遍历的未知数
- `[right, n - 1]`: 全是 2

然后考虑细节就可以了：
- `nums[i] == 0`: 只需要把 `left + 1` 和 `i` 位置交换一下，然后 `left++`, i++ 即可
- `nums[i] == 1`: 不需要经行任何交换，只要 `i++` 就可以了
- `nums[i] == 2`: 把 `right - 1` 和 `i` 位置交换，把 `right--` 就可以了
  > `i` 不能加 1, 因为**交换完后，i 的位置依然是未知数**

最后只需要考虑初识情况就可以了：为了满足那些区间内的情况，**`left` 必须为 -1, `right` 必须为 n**

```Java
public void sortColors(int[] nums) {
	/**
	定义三个指针 left, i, right 
		[0, left]: 全是 0 的数 
		[left + 1, i - 1]: 全是 1
		[i, right - 1]: 待遍历的未知数
		[right, n - 1]: 全是 2
	*/ 
	// 为了满足上面的条件 left 必须从 -1 开始，right 必须从 n 开始
	int left = -1, i = 0, n = nums.length, right = n;

	while (i < right) {
		if (nums[i] == 0) {
			// 把 left + 1 和 i 的位置交换, i++, left++
			swap(++left, i++, nums);
		} else if (nums[i] == 1) {
			// 不需要交换，i++ 就可以
			i++;
		} else {
			// nums[i] == 2 把后面的 right - 1 与 i 交换，由于 right - 1 的内容是没有处理过的，因此 i 不需要加 1
			swap(i, --right, nums);
		}
	}
}

private void swap(int i, int j, int[] arr) {
	int tmp = arr[i];
	arr[i] = arr[j];
	arr[j] = tmp;
}
```


### [LC912. 排序数组](https://leetcode.cn/problems/sort-an-array/)
这个题目需要有 [LC75. 颜色分类](<#[LC75. 颜色分类](https //leetcode.cn/problems/sort-colors/)>) 这个基础，因为快排中元素的优化就是需要涉及到这道题目的思想

思路：
1. 随机找到一个数 `randomNum`，把小于这个数的放在一堆，等于这个数的放在一堆，大于这个数的放在一堆
	- `[start, left]`: 小于 `randomNum`
	- `[left + 1, i - 1]`: 等于 `randomNum`
	- `[i, right - 1]`: 未知
	- `[right, end]`: 大于 `randomNum` 
	> 随机找一个数可以让它的时间复杂度趋于 $N \times \log_{N}$ 
2. 然后**进行分治**，由于**等于 randomNum 的数已经排序好**，那么就只需要再排序 `[start, left]` 和 `[right, end]` 这两个区间就可以了

```Java
Random random = new Random();

public int[] sortArray(int[] nums) {
	qsort(0, nums.length - 1, nums);

	return nums;
}

// 排序 [start, end] 内的元素
private void qsort(int start, int end, int[] nums) {
	if (start >= end) return;
	// 先随机获取一个元素
	int randomNum = nums[random.nextInt(start, end + 1)];
	/**
	[0, left]: < randomNum
	[left + 1, i - 1]: = randomNum
	[i, right - 1]: 未知
	[right, n]: > randomNum
	*/
	int left = start - 1, i = start, right = end + 1;
	while (i < right) {
		if (nums[i] < randomNum) {
			swap(++left, i++, nums);
		} else if (nums[i] == randomNum) {
			i++;
		} else {
			// nums[i] > randomNum
			swap(i, --right, nums);
		}
	}

	// 元素值为 randomNum 已经排序好，那么就需要排序前后两个区间了
	qsort(start, left, nums);
	qsort(right, end, nums);
}

private void swap(int i, int j, int[] nums) {
	int t = nums[i];
	nums[i] = nums[j];
	nums[j] = t;
}
```
