分治是分而治之，**它是将一个大的问题拆分为若干的相同/相似的小问题**，而这些小问题是可以快速地解决的，从而推广到解决大问题

它分为两个模块：快排和归并

## 快排
### [LC75. 颜色分类](https://leetcode.cn/problems/sort-colors/)

这个是把这个数组分为四个部分，需要使用三个指针

定义三个指针 `left`, `i`, `right` 
- `[0, left]`: 全是 0 的数 
- `[left + 1, i - 1]`: 全是 1
- `[i, right - 1]`: 待遍历的未知数
- `[right, n - 1]`: 全是 2

然后考虑细节就可以了：
- `nums[i] == 0`: 只需要把 `left + 1` 和 `i` 位置交换一下，然后 `left++`, i++ 即可
- `nums[i] == 1`: 不需要经行任何交换，只要 `i++` 就可以了
- `nums[i] == 2`: 把 `right - 1` 和 `i` 位置交换，把 `right--` 就可以了
  > `i` 不能加 1, 因为**交换完后，i 的位置依然是未知数**

最后只需要考虑初识情况就可以了：为了满足那些区间内的情况，**`left` 必须为 -1, `right` 必须为 n**

```Java
public void sortColors(int[] nums) {
	/**
	定义三个指针 left, i, right 
		[0, left]: 全是 0 的数 
		[left + 1, i - 1]: 全是 1
		[i, right - 1]: 待遍历的未知数
		[right, n - 1]: 全是 2
	*/ 
	// 为了满足上面的条件 left 必须从 -1 开始，right 必须从 n 开始
	int left = -1, i = 0, n = nums.length, right = n;

	while (i < right) {
		if (nums[i] == 0) {
			// 把 left + 1 和 i 的位置交换, i++, left++
			swap(++left, i++, nums);
		} else if (nums[i] == 1) {
			// 不需要交换，i++ 就可以
			i++;
		} else {
			// nums[i] == 2 把后面的 right - 1 与 i 交换，由于 right - 1 的内容是没有处理过的，因此 i 不需要加 1
			swap(i, --right, nums);
		}
	}
}

private void swap(int i, int j, int[] arr) {
	int tmp = arr[i];
	arr[i] = arr[j];
	arr[j] = tmp;
}
```


### [LC912. 排序数组](https://leetcode.cn/problems/sort-an-array/)
这个题目需要有 [LC75. 颜色分类](<#[LC75. 颜色分类](https //leetcode.cn/problems/sort-colors/)>) 这个基础，因为快排中元素的优化就是需要涉及到这道题目的思想

思路：
1. 随机找到一个数 `randomNum`，把小于这个数的放在一堆，等于这个数的放在一堆，大于这个数的放在一堆
	- `[start, left]`: 小于 `randomNum`
	- `[left + 1, i - 1]`: 等于 `randomNum`
	- `[i, right - 1]`: 未知
	- `[right, end]`: 大于 `randomNum` 
	> 随机找一个数可以让它的时间复杂度趋于 $N \times \log_{N}$ 
2. 然后**进行分治**，由于**等于 randomNum 的数已经排序好**，那么就只需要再排序 `[start, left]` 和 `[right, end]` 这两个区间就可以了

```Java
Random random = new Random();

public int[] sortArray(int[] nums) {
	qsort(0, nums.length - 1, nums);

	return nums;
}

// 排序 [start, end] 内的元素
private void qsort(int start, int end, int[] nums) {
	if (start >= end) return;
	// 先随机获取一个元素
	int randomNum = nums[random.nextInt(start, end + 1)];
	/**
	[0, left]: < randomNum
	[left + 1, i - 1]: = randomNum
	[i, right - 1]: 未知
	[right, n]: > randomNum
	*/
	int left = start - 1, i = start, right = end + 1;
	while (i < right) {
		if (nums[i] < randomNum) {
			swap(++left, i++, nums);
		} else if (nums[i] == randomNum) {
			i++;
		} else {
			// nums[i] > randomNum
			swap(i, --right, nums);
		}
	}

	// 元素值为 randomNum 已经排序好，那么就需要排序前后两个区间了
	qsort(start, left, nums);
	qsort(right, end, nums);
}

private void swap(int i, int j, int[] nums) {
	int t = nums[i];
	nums[i] = nums[j];
	nums[j] = t;
}
```

### [LC215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)
这个题目是对 [LC912. 排序数组](#[LC912.%20排序数组](https%20//leetcode.cn/problems/sort-an-array/)) 扩展。

思路：
1. 前面一部分是执行 [LC912. 排序数组](#[LC912.%20排序数组](https%20//leetcode.cn/problems/sort-an-array/)) ，把它分为三个部分
	- `[start, left]`: 小于 `randomNum`
	- `[left + 1, i - 1]`: 等于 `randomNum`
	- `[i, right - 1]`: 未知
	- `[right, end]`: 大于 `randomNum` 
2. 然后就可以根据条件来递归
	- **右边那块区间长度大于 `k`，说明 `k` 就在右边那块区间内**，那么就只需要处理右边那一部分就可以了
	- 如果**上面条件不满足**，那么就可以找一下中间的那块区间，**如果右边的区间加中间区间的长度比 `k` 大，那么 `k` 就在中间那块区间内**，直接返回就可以了
	- **如果都不满足，那么就在左边那块区间**，但是在处理左边那块区间的时候，**需要把 `k` 减去中间和右边区间长度之和**，因为题目要求是求第 `k` 大的值

```Java
Random random = new Random();
public int findKthLargest(int[] nums, int k) {
	return qoption(0, nums.length - 1, nums, k);
}


public int qoption(int l, int r, int[] nums, int k) {
	if (l > r) return -1;
	// random.nextInt(l, r + 1)
	int randomNum = nums[r];

	/**
	先遍历一次，把它分为这几个部分
		[l, left]: < randomNum
		[left + 1, i - 1]: = randomNum
		[i, right - 1]: 未知
		[right, r]: > randomNum
	*/
	int left = l - 1, i = l, right = r + 1;
	while (i < right) {
		if (nums[i] < randomNum) swap(++left, i++, nums);
		else if (nums[i] == randomNum) i++;
		else swap(i, --right, nums);
	}

	// 根据条件，判断它是否是第 k 个元素，然后递归
	if (r - right + 1 >= k) return qoption(right, r, nums, k); // 右边区间长度大于等于 k 
	else if (r - left >= k) return nums[right - 1]; // 说明 k 在中间的那段区间
	else return qoption(l, left, nums, k - (r - left)); // 在左边那段区间, 因为去掉了 
}


private void swap(int i, int j, int[] nums) {
	int t = nums[i];
	nums[i] = nums[j];
	nums[j] = t;
}
```
### [LCR 159. 库存管理 III](https://leetcode.cn/problems/zui-xiao-de-kge-shu-lcof/)

这倒题目和 [LC215. 数组中的第K个最大元素](#[LC215.%20数组中的第K个最大元素](https%20//leetcode.cn/problems/kth-largest-element-in-an-array/)) 类似，需要有 [LC912. 排序数组](#[LC912.%20排序数组](https%20//leetcode.cn/problems/sort-an-array/)) 这个相关的知识点

思路：
1. 先遍历一次，分为三块
	- `[start, left]`: 小于 `randomNum`
	- `[left + 1, i - 1]`: 等于 `randomNum`
	- `[i, right - 1]`: 未知
	- `[right, end]`: 大于 `randomNum` 
2. 根据情况来筛选出对应的条件
	- 在**左侧的区间**，那么还需要**遍历一次**，但是不需要排序中间和右侧的区间了
	- 在**中间的区间（包含左侧区间的最右边和右侧区间的最左边）**，那么就可以**直接返回**
	- 在**右侧区间**，那么依然还需要**遍历一次**，但是 cnt 就需要减去相关的元素了


```Java
Random random = new Random();

public int[] inventoryManagement(int[] stock, int cnt) {
	int end = quickSelect(0, stock.length - 1, stock, cnt);

	int[] result = new int[cnt];
	for(int i = 0; i < end; i++) result[i] = stock[i];

	return result;
}

private int quickSelect(int l, int r, int[] nums, int cnt) {
	if (l > r) {
		return -1;
	}
	// int randomNum = nums[random.nextInt(l, r + 1)];
	int randomNum = nums[r];
	int left = l - 1, i = l, right = r + 1;
	while (i < right) {
		if (randomNum > nums[i]) swap(i++, ++left, nums); 
		else if (randomNum == nums[i]) i++;
		else swap(--right, i, nums);
	}
	// [l, left]: < randonNum  [left + 1, right - 1]: == randonNum
	if (left - l + 1 > cnt) return quickSelect(l, left, nums, cnt);
	else if (right - l >= cnt) return cnt + l;
	else return quickSelect(right, r, nums, cnt - (right - l));
}

private void swap(int i, int j, int[] nums) {
	int t = nums[i];
	nums[i] = nums[j];
	nums[j] = t;
}
```
## 归并
归并和快排很像的。

快排是**先排再分**：先确定元素的位置，然后一个区间一个区间来排序，类似与**二叉树的前序遍历**

归并是**先分再排**：先分到不能分为止，分到只有两个元素为止（一个元素是直接返回，不需要排序），然后把那两块区间看为两个有序的数组，类似**二叉树的后续遍历**
### [LC912. 排序数组](https://leetcode.cn/problems/sort-an-array/)

这个题目归并排序的一个入门题目，思路就是归并排序的思路（上面刚刚讲述过，这里就不复述了）

```Java   
public int[] sortArray(int[] nums) {
	mergeSort(0, nums.length - 1, nums);
	return nums;
}

private void mergeSort(int l, int r, int[] nums) {
	if (r <= l) return; // 只有一个元素，那么就不需要排序了
	
	int mid = (r - l) / 2 + l;

	// 先排左边，再排右边
	mergeSort(l, mid, nums);
	mergeSort(mid + 1, r, nums);

	// 合并两个有序数组
	int[] tmp = new int[r - l + 1];
	int lIndex = l, rIndex = mid + 1, tIndex = 0;
	for (; lIndex <= mid && rIndex <= r; ) {
		if (nums[lIndex] < nums[rIndex]) tmp[tIndex++] = nums[lIndex++];
		else tmp[tIndex++] = nums[rIndex++];
	}

	// 处理残留项
	while (lIndex <= mid) tmp[tIndex++] = nums[lIndex++];
	while (rIndex <= r) tmp[tIndex++] = nums[rIndex++];
	// 把 tmp 赋值回去
	tIndex = 0;
	for (int i = l; i <= r; i++) nums[i] = tmp[tIndex++];
}
```
