# 02-二叉树

## 题目

### [LC129. 求根节点到叶节点数字之和](https://leetcode.cn/problems/sum-root-to-leaf-numbers/)

思路：
1. 计算当前的值：`curVal = curVal * 10 + root.val`
2. 如果是**叶子节点**，那么还需要**统计当前的值**的大小
3. 因此需要有 3 个变量：
	1. `root`: 当前二叉树的节点
	2. `curVal`: 存储之前的值
	3. `list`: 存储满足条件的值
4. 递归执行完后，重新再遍历 `list` 一次，计算总和

```Java
public int sumNumbers(TreeNode root) {
	List<Integer> list = new LinkedList<>();
	dfs(root, 0, list);

	int result = 0;
	for (int x : list) result += x;

	return result;
}

private void dfs(TreeNode root, int curVal, List<Integer> list) {
	if (root == null) return;

	curVal = curVal * 10 + root.val;
	if (root.left == null && root.right == null) {
		// 这时候就需要添加了
		list.add(curVal);
		return;
	}

	// 不需要判断，因为有 root == null 这个条件了
	dfs(root.left, curVal, list);
	dfs(root.right, curVal, list);
}
```

### [LC814. 二叉树剪枝](https://leetcode.cn/problems/binary-tree-pruning/)

思路：
1. 由于它是**先要获取到子节点的信息**，那么才能判断它是否需要删除，因此**采用后序遍历**
2. 如果**左边为空，右边也为空，而且 `val` 是为 0**，那么就可以**修剪**了
3. 由于需要判断一下左右是否满足，因此需要返回一个 `boolean` 类型，判断是否要删除

```Java
public TreeNode pruneTree(TreeNode root) {
	if(!prune(root)) root = null;
	return root;
}

// false 返回表示需要修剪 true 表示不需要
private boolean prune(TreeNode root) {
	if (root == null) return false; // 需要修剪

	boolean l = prune(root.left);
	boolean r = prune(root.right);

	
	if (!l) root.left = null;
	if (!r) root.right = null;

	// l, r 其中一个为 true 或者 root.val 为 1 ，那么就不需要修剪
	return root.val == 1 || l || r ; // 说明这个根结点也需要排除 不过需要交给上游修剪
}
```
