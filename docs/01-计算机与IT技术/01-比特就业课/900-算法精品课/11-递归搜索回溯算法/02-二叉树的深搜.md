### [LC129. 求根节点到叶节点数字之和](https://leetcode.cn/problems/sum-root-to-leaf-numbers/)

思路：
1. 计算当前的值：`curVal = curVal * 10 + root.val`
2. 如果是**叶子节点**，那么还需要**统计当前的值**的大小
3. 因此需要有 3 个变量：
	1. `root`: 当前二叉树的节点
	2. `curVal`: 存储之前的值
	3. `list`: 存储满足条件的值
4. 递归执行完后，重新再遍历 `list` 一次，计算总和

```Java
public int sumNumbers(TreeNode root) {
	List<Integer> list = new LinkedList<>();
	dfs(root, 0, list);

	int result = 0;
	for (int x : list) result += x;

	return result;
}

private void dfs(TreeNode root, int curVal, List<Integer> list) {
	if (root == null) return;

	curVal = curVal * 10 + root.val;
	if (root.left == null && root.right == null) {
		// 这时候就需要添加了
		list.add(curVal);
		return;
	}

	// 不需要判断，因为有 root == null 这个条件了
	dfs(root.left, curVal, list);
	dfs(root.right, curVal, list);
}
```

### [LC814. 二叉树剪枝](https://leetcode.cn/problems/binary-tree-pruning/)

思路：
1. 由于它是**先要获取到子节点的信息**，那么才能判断它是否需要删除，因此**采用后序遍历**
2. 如果**左边为空，右边也为空，而且 `val` 是为 0**，那么就可以**修剪**了
3. 由于需要判断一下左右是否满足，因此需要返回一个 `boolean` 类型，判断是否要删除

```Java
public TreeNode pruneTree(TreeNode root) {
	if(!prune(root)) root = null;
	return root;
}

// false 返回表示需要修剪 true 表示不需要
private boolean prune(TreeNode root) {
	if (root == null) return false; // 需要修剪

	boolean l = prune(root.left);
	boolean r = prune(root.right);

	
	if (!l) root.left = null;
	if (!r) root.right = null;

	// l, r 其中一个为 true 或者 root.val 为 1 ，那么就不需要修剪
	return root.val == 1 || l || r ; // 说明这个根结点也需要排除 不过需要交给上游修剪
}
```

### [LC98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)
二叉搜索树的**验证条件**：
1. 左子树是二叉搜索树
2. 右子树是二叉搜索树
3. 中间的值比左子树最大的大，比右子树最小的小

思路：
1. 通过**中序遍历**，判断中序遍历是否有序就可以了
2. 使用全局变量 `prev`，**用来表示之前的节点的数值**，可以比较方便地判断当前的节点与上一个节点的大小

```Java
long prev = Long.MIN_VALUE; // 需要考虑到最左边下面的节点为 Integer.MIN_VALUE 的情况，因此需要使用 Long

public boolean isValidBST(TreeNode root) {
	if (root == null) return true; // 空子树也是二叉搜索树
	// 判断左边 再判断核心 最后判断右边（使用剪枝的思想）
	return isValidBST(root.left) && (prev < (prev = root.val)) && isValidBST(root.right);
}
```

### [LC230. 二叉搜索树中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)
这个思路和 [LC98. 验证二叉搜索树](<#[LC98. 验证二叉搜索树](https //leetcode.cn/problems/validate-binary-search-tree/)>) 差不多，只需要添加 `count` 和 `ret` 就可以了：
- `count`: 统计当前节点的第几位了
- `ret`: 获取返回值

```Java
int count;
int ret;
public int kthSmallest(TreeNode root, int k) {
	count = k; // 初始化 k
	dfs(root);
	return ret;
}

public void dfs(TreeNode root) {
	// 空树，直接返回
	if (root == null) return;

	// 遍历左子树
	dfs(root.left);
	if (count <= 0) return; // 在左子树内，剪枝，不需要遍历后面的了
	
	// 左子树已经遍历完 并且 count > 0         
	count--;
	if (count == 0) { // 条件符合
		ret = root.val;
		return;
	}
	
	// 到这里，说明左子树和根结点都不满足，那么就遍历右子树
	dfs(root.right);
}
```

### [LC257. 二叉树的所有路径](https://leetcode.cn/problems/binary-tree-paths/)
思路：`path` 表示路径
1. 如果**是叶子节点**，那么就可以直接把相关的**结果存储在 `result`** 中
2. 如果**不是叶子节点**，那么就要把**箭头和相关的值给添加到 `path` 中**，然后递归执行相关的内容

细节：
1. 使用一个**全局变量来存储结果**，使用 **`StringBuilder` 来存储当前的路径**
2. 但是使用 `StringBuilder` 的时候，**如果不新 `new` 一个对象，那么就需要考虑恢复现场**

```Java
List<String> result = new LinkedList<>();

public List<String> binaryTreePaths(TreeNode root) {
	dfs(root, new StringBuilder());

	return result;
}

// 使用局部变量 path , 如果使用 StringBuilder 那么就需要考虑恢复现场的情况，
// 不过可以通过 new 一个新的对象来解决
void dfs(TreeNode root, StringBuilder _path) {
	if (root == null) return;
	
	StringBuilder path = new StringBuilder(_path);
	path.append(root.val); // 先添加 后续就不需要添加了
	
	if (root.left == null && root.right == null) {
		// 叶子节点
		result.add(path.toString());
		return;
	}

	// 更新左右子树，然后递归 
	path.append("->");
	dfs(root.left, path);
	dfs(root.right, path);
}
```
