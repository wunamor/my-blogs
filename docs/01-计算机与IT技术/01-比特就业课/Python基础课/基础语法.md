# python 基础语法

# 运算符
1. 算数运算符
   -  `//` 表示向下取整 `7 // 3 -> 2`  `-7 // 3 -> -3`
   ![](images/python%20基础语法-算数运算符-向下取整.png)
   - `%` 取余，与 `Java` 不同，它是依赖于**向下取整** `a % b = a - (b * (a // b))`
   ![](images/python%20基础语法-算数运算符-取余.png)
2. 逻辑运算符
   - 问题：`print(f'{0.1 + 0.2 == 0.3}')` 结果是什么？
     - 答案是 `False`
     - 因为浮点数有精度问题
     - 解决方法：两数相减的误差的小于某一个值即可
     ![](images/python%20基础语法-浮点数精度解决方法.png)
