# 单例模式
> 全局只需要创建一个，也**只能有一个**，比如太阳/月亮等

## 类型
| 类型 | 思想 | 代码图片 |
| :---: | :---: | :---: |
| 懒汉模式 | 能不创建就不创建，但是可能会有线程安全的问题 | ![](images/单例模式-懒汉模式.png) |
| 饿汉模式 | 尽快创建，在项目启动/应用调用的时候就创建 | ![](images/单例模式-饿汉模式.png) |
