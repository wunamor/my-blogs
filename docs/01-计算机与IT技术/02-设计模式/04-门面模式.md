# 04-门面模式

在有多个子模块的情况下，门面模式（外观模式）可以发挥一个比较好的作用。

就拿线上挂号为例，如果没有门面模式，不同医院系统之间的调用的接口是不同，比如：支付接口，挂号接口，报销接口等

**显然如果想要统一管理，是比较复杂的，所以就需要引入统一的接口，这样可以比较方便**
> 在现实中，上诉挂号的问题已经解决了。可以在 支付宝 搜索 挂号 然后点击 医疗健康 。这个就是体现了门面模式

---

再拿 SpringBoot 初始化为例，它初始化是需要加载配置项，加载第三方 Bean，加载个人项目中的 Bean 等步骤。

显然，这些步骤如果需要调用方一个一个调用，那么将会很麻烦。因此可以使用门面模式，**对外只提供一个 init 的接口**，把这些步骤封装起来，调用者就可以不需要一个一个调用，考虑先后顺序了
