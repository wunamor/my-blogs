# Docker 出错总结

1. `1Panel` 中应用访问 `504`
  ![](images/Docker%20出错总结-1panel中应用访问504-错误场景.png)
   - 前景：
     - 当我访问内容的，需要等待比较长的时候后，报出 `504 Gateway Time-out`
     - 我之前**访问的时候是可以正常访问**的
   - 解决思考：
     - **访问一下同一个云服务器的其他网址** -- 发现是同样的问题
     - 去访问另一台好的服务器，更新一下相关设置 -- 发现也是好的
     - 所以，不是更新的问题，也不是容器的问题，那就是中转站 `OpenResty` 的问题
   - 解决措施
     - 问 `AI`, 让它排除掉其他的情况后，把上诉的条件告诉 `AI`，得出如图结论
     ![](images/Docker%20出错总结-1panel中应用访问504-解决方法.png)
     - 接下去执行代码 
        ```Bash
        systemctl restart docker # 重启 Docker
        1pctl restart # 重启 1Panel
        ```
   - 产生原因：由于系统更新，云服务器厂商**重启了云服务器**，导致的问题
