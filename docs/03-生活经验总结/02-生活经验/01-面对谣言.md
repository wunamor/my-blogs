# 面对谣言的生活经验
> 本文章总结一下遇到的**谣言**的经验总结，
> 目标是 可以**独立思考**，防止盲目跟风

## 例子
1. 315-淀粉肠
   - 前因：315曝光了某些产品后，忽然淀粉肠就被某个“媒体”通过**一篇文章**说明有害性，从而引起公众讨论
   - 如何发现的：
     1. 我首先对此**不坚信**，当作一个“茶后话题”来看待
     2. 之后我看了一个视频（找不到了，是一个类似学生的年轻小伙录制的），他合理的分析了那篇文章的问题：
        - 文章的**来源不权威**
        - 文章内部引用的**来源也是不权威**
     3. 因此我对此**很感兴趣**，特意去**看了一遍315所有的内容**，发现果真没有讲到，就发现了这次谣言
   - 总结：**非权威的人**的话**不可轻信** 
2. 国安部-警惕躺平
   - 前因：我是看见 章xx 说的后，关注到了这一篇文章
   - 如何发现的：
     1. 我之前在某些up主下面说 章xx 的什么什么不好，因此**有一定的警惕之心**
     2. 于是我就**通过视频中的关键字**，在微信上查询到相关的文章，并且阅读了
     3. 发现文章阐述的是 **警惕境外势力鼓动躺平**，而不是 **让年轻人不要躺平**
     4. 所以我就发现 章xx 的内容是 **张冠李戴**，而且重新看了一下视频，发现他说的内容是泛泛而谈，讲到了具体操作，但是**没有很详细，也没有说明为什么**
   - 总结：
     - 在抨击某个视频/文章 的时候，**一定要清楚他讲述的目的是什么**
     - 为什么 章xx 不会被封？：
       1. 他说的**问题的确存在**
       2. 他说的措施虽然假大空，但是也**有一定的借鉴意义**

## 总结：如何避免被谣言蛊惑呢？
1. 那个内容**一般是要出自权威的地方**，比如专家/权威媒体发布的文章/视频等，但是**不能完全相信**，理由：
   1. 消息可能是**过时**了
   2. 消息可能会**被裁剪**
2. 如果是**视频**，一般不少于10分钟（个人主观感受，反正**不能太短**），因为**时间太短，一般说不出 前因后果，分析理由，如何解决等内容**
3. 一定要**结合当时所处的上下文，分析出文章所要表达的意思**再讨论
