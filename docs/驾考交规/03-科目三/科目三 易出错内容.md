# 科目三（手动） 易出错内容
## 如何停下来？
- 先踩离合，踩离合无论何时一定要快
- **根据距离**慢慢踩刹车
## 如何起步？(难QaQ)
- 缓慢松离合，在此期间**一定要踩好刹车**，以防溜车
- 接下去感到有点起步 **（车辆比较抖）**的时候，慢慢松刹车
## 如何转弯？
- 缓慢转，根据线路转
- 如果换车道
  - 先开转向灯
  - 接着看一眼后视镜，只需**看一眼即可，不要看太长时间**
  - 如果条件允许，以合适的速度转弯
## 如何换挡
- 先踩油门
- 速度合适的时候松油门，踩离合 **（速度要快）**
- 换挡
- 慢慢松开离合，感到**停顿一下**的时候 **（大约1/2）**就可以**完全松开离合**了
  |       | 可以换挡的速度 | 完全放开挡位的速度 |
  | :---: | :------------: | :----------------: |
  |   1   |      0-10      |         10         |
  |   2   |     10-20      |         20         |
  |   3   |     20-30      |         30         |
  |   4   |     30-40      |         40         |
  |   5   |     40 <=      |         ?          |

- 当看见行人过马路的时候就要松开油门了
