# 科目二（手动） 出错内容
## 操作注意点
### 方向盘
- 要**匀速**，不要转到一半停下来
- 如果感觉**转不过来**，方向盘转得太慢，就**踩离合**，**把速度**降下来（感觉这个最反直觉，**松开反而动的快**，电瓶车/自行车都没有这样的功能）
### 离合
- 离合必须要**踩到底**才能调节挡位
- 离合需要**快踩慢放**：即要一口气踩下去，分两次放出来（如果“快放”容易熄火）
### 手刹
- 放的时候需要**按下按钮**+**拉升一下**
